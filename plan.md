# Plan — Template Premium : Centre de Formation Professionnelle

## Contexte
Création d'un template web premium pour organismes de formation professionnelle (OF, CFA, écoles de reconversion) basé sur les documents de référence sector-19-formation.md et 19_centre_formation_professionnelle.md.

## Stages

### Stage 1 — Design System & Architecture
- Définir le design system complet (couleurs, typographie, espacement, composants)
- Créer le document design.md avec palette, typographie, layout grid, animations
- Architecture des pages et routing

### Stage 2 — Content & Assets Generation
- Générer les images du template (hero, apprenants, formateurs, campus)
- Créer le contenu démo réaliste (formations, témoignages, chiffres)
- Préparer les données JSON pour les formations, témoignages, statistiques

### Stage 3 — Development (vibecoding-webapp-swarm)
- Charger le skill vibecoding-webapp-swarm
- Construire le template React/Next.js avec toutes les pages publiques
- Implémenter le design system, animations, composants réutilisables
- Pages : Accueil, Formations, Fiche Formation, Financement, Entreprises, À Propos, Blog, Contact
- Espace Apprenant (simplifié) + Admin (simplifié)

### Stage 4 — Polish & Deploy
- SEO metadata, Schema.org markup
- Accessibilité WCAG AA
- Responsive final check
- Déploiement

## Skills Required
- web-template-library (guide de référence)
- vibecoding-webapp-swarm (développement React)
- generate_image (assets visuels)

## Livrables
- Template React complet et déployé
- Design system documenté
- Assets générés
